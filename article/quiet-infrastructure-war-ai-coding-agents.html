Issue 01 Week of 2026-09-30 – 2026-10-06 AI × Infrastructure

The quiet infrastructure war inside crypto's AI boom.

Nineteen of the most technical founders in crypto stopped waiting for OpenAI and Anthropic to build secure coding agents. This week, they shipped their own — tools designed to write, audit, and deploy code holding billions in assets.

5 min read · 19 of 103 tracked · 111 signals · Sources: X · Farcaster · Github

The most technical founders in crypto are no longer waiting for OpenAI or Anthropic to build secure AI coding tools. They're building their own. This week, at least five teams shipped infrastructure that lets AI agents write, test, and deploy code — with security constraints designed for systems that hold billions.

What's happening under the hood

Paradigm's CTO Georgios Konstantopoulos shipped nanocodex — a harness that wraps both OpenAI's Codex and Anthropic's Claude. Harnesses are the wrappers that give AI models the ability to execute code, run tests, and push to production. His version lets you spawn both models as subagents working together.

Meanwhile, NEAR's Alexander Skidanov announced an AI agent that can formally verify code — mathematically proving it does what it claims. Paradigm's Dan Robinson pushed 14 commits this week to a similar tool for Solidity smart contracts.

Who's moving

Georgios Konstantopoulos — Paradigm CTO merged code combining Codex and Claude into a single agent framework. He's also considering paid access to Cyclops — Paradigm's internal security tool.

Basically codex security but for serious immutable fast crypto infrastructure that can hold billions of dollars. — Georgios Konstantopoulos, on X

Alexander Skidanov — NEAR co-founder claimed the #1 spot on Lean Eval, the benchmark for formal verification agents.

We now have a very capable and cheap formal verification agent, and will share how we use it to formally prove NEAR. — Alexander Skidanov, on X

Jack Zampolin — Pion founder has been building gents, an open-source coding agent framework. His GitHub shows active work on evaluation suites for both Codex and Claude.

I'd be about 200k lines in. — Jack Zampolin, on X

Brian Armstrong — Coinbase CEO is focused on the infrastructure for agents, not the agents themselves — unveiling an API designed for autonomous systems.

Your agent can now see your portfolio, trade crypto, stocks, and derivatives. — Brian Armstrong, on X

Lefteris Karapetsas — Rotki founder added agent interfaces to his portfolio tracker.

You can interact with the data in any way you want via MCP and your favorite agent. — Lefteris Karapetsas, on X

The consensus

Everyone agrees models themselves are becoming commodities.

Models are going to be commoditized and compute is the real resource. — Jack Zampolin

The value is moving to execution infrastructure — the harnesses, security layers, and APIs that turn language models into reliable developers.

The dissent

Not everyone thinks this ends well.

Joe McCann (cybersecurity asymmetry): Agentic war coming. 10,000 tokens per second is unfathomable speed... it will create an endless game of cyber defense against relentless cyber attacks.

Haseeb Qureshi (systemic financial risk): AI agent-caused bank runs!

Jeff Garzik (user sovereignty): AI assistants like Muse will succeed when the human self-sovereignty barrier is respected, legally and practically.

Projects positioned to benefit

  • Paradigm's internal tooling — nanocodex, CyclopsIf they commercialize, they have first-mover advantage in enterprise-grade agent security for crypto infrastructure.
  • NEAR ProtocolTheir formal verification agent gives them a concrete technical moat. Provable security is valuable when competitors can't match it.
  • CoinbaseArmstrong is building the financial backend for agents, not the agents themselves. The picks-and-shovels play.
  • Pion (gents)Open-source positioning could capture developer mindshare as harness standards emerge.
  • RotkiEarly MCP integration means compatibility with whatever agent ecosystem wins.

What this likely means

Security auditing firms face disruption. If agents can formally verify code, the value shifts from human auditors to teams running verification agents.

Protocol teams will need their own agent infrastructure. Relying on generic tools becomes too risky when billions are at stake.

The attack surface expands faster than defenses. McCann's 10,000 tokens-per-second point implies offense scales better than defense — at least in the near term.

Open-source harnesses become critical infrastructure. Whoever sets the standards controls the security assumptions.

What to watch

  1. Whether Paradigm actually opens Cyclops to external customers — signal of commercial intent, and the moment "AI security for crypto" becomes a market.
  2. NEAR's formal verification agent applied to non-NEAR contracts — proving generalizability beyond their own protocol.
  3. Any major protocol breach traced to an AI coding agent — this would reshape the entire conversation overnight.
